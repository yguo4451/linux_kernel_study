# 19. 多终端进入同一个系统：串口控制台 vs 登录会话

> 工具链扩展篇。解决"一个 QEMU 系统只能一个终端"的痛点，让宿主机开任意多个终端同时操作同一个 Linux 系统。

## 问题根源：-nographic 把唯一串口焊死到 stdio

`run_qemu.sh` 的 `-nographic` 做两件事：不建图形窗口 + 把 QEMU 的**第一个串口 `ttyAMA0` 直接接到当前终端 stdin/stdout**。所以现状是一条 1:1 的物理线路：

```
宿主机终端  ←stdin/stdout→  QEMU  ←串口 ttyAMA0→  guest console
```

一条线，天然只能一个终端。

## 两条路：加串口 vs 走网络

| 思路 | 做法 | 终端数 | 复杂度 |
|------|------|--------|--------|
| ① 硬件线路 | QEMU 多开串口，每个串口跑一个 `getty` | 固定 N 个 | 高 |
| ② 网络登录 | guest 跑 `telnetd`，宿主机 telnet 进去 | **任意多个** | 低 |

选择 ②：复用已有 slirp 网络，QEMU 加一行 `hostfwd`，guest 起 `telnetd`。

## 三个关键组件

### 1. QEMU 端口转发 hostfwd（`run_qemu.sh`）

```bash
-netdev user,id=net0,hostfwd=tcp::2323-:23
```

宿主机 2323 → guest 23（telnet 默认端口）。端口用环境变量 `TELNET_PORT` 可配。

### 2. telnetd 登录会话（`build_in_container.sh` 的 /init）

```sh
telnetd -l /bin/sh &   # -l 指定登录后执行的 shell（实验环境免认证）
```

### 3. devpts 伪终端（关键坑！）

**没有 devpts，telnetd 起不来**——它要给每个会话分配一个伪终端 `/dev/pts/N`：

```sh
mkdir -p /dev/pts
mount -t devpts devpts /dev/pts
```

踩坑实录：最初只挂载了 proc/sysfs/devtmpfs/tmpfs，漏了 devpts，导致 telnetd 接受连接后无法分配 PTY，进程静默退出、23 端口消失。补挂 devpts 后立即恢复。

## 完整的 /init（固化后）

```sh
#!/bin/sh
mount -t proc proc /proc
mount -t sysfs sysfs /sys
mount -t devtmpfs devtmpfs /dev
mkdir -p /dev/pts
mount -t devpts devpts /dev/pts
mount -t tmpfs tmpfs /tmp
ifconfig lo up
ifconfig eth0 up
udhcpc -i eth0 &
telnetd -l /bin/sh &          # 网络登录会话
echo "Welcome to your own Linux!"
setsid cttyhack sh            # 串口控制台会话
```

## 使用步骤

```sh
# 终端 1：串口控制台（原方式不变）
./scripts/run_qemu.sh

# 终端 2、3、4…：任意多个网络登录会话（同一套系统）
nc 127.0.0.1 2323        # 或 telnet 127.0.0.1 2323
```

## 概念辨析：为什么这两个"终端"本质不同

| | 串口控制台（ttyAMA0） | telnet 会话（pts/N） |
|---|---|---|
| 通道 | 虚拟串口 | TCP 连接（经 hostfwd） |
| 登录程序 | `cttyhack sh` | `telnetd -l /bin/sh` |
| 伪终端 | 无（直接 tty） | `/dev/pts/N`（devpts 分配） |
| 数量 | 1 个 | 任意多个 |
| 是否走网络 | 否 | 是 |

这也解释了 Linux 里"控制台 console / 终端 tty / 伪终端 pts"三者的区别——串口是物理终端（tty），telnet 会话是内核用 devpts 虚拟出来的伪终端（pts），两者最终都套在同一个 `sh` 上，操作同一套文件系统。

## 验证方法（共享同一系统的铁证）

```sh
# telnet 会话里
touch /tmp/PROOF_FROM_TELNET

# QEMU console 里
ls -l /tmp/PROOF_FROM_TELNET   # 能看见 → 同一套根文件系统
```

辅助脚本：`scripts/telnet_verify.py`（端到端验证，过滤 telnet 协商字节 IAC）。
