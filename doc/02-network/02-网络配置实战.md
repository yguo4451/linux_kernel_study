# 网络配置实战：从零网络到 ping 通外网

对应环境：QEMU arm64 最小 Linux 系统（BusyBox + initramfs）。

## 上网四要素

一台机器要上网，需要四样东西：

| 要素 | 作用 | 配置命令 |
|---|---|---|
| IP 地址 | 我是谁 | `ifconfig eth0 10.0.2.15` |
| 子网掩码 | 哪些是邻居 | `ifconfig eth0 ... netmask 255.255.255.0` |
| 默认网关 | 外网找谁 | `route add default gw 10.0.2.2` |
| DNS 服务器 | 域名翻译 | `echo "nameserver 10.0.2.3" > /etc/resolv.conf` |

关键认知：`ifconfig` 只配前两个；后两个要么手动 `route` + `resolv.conf`，要么交给 DHCP（`udhcpc -i eth0`）一把梭。

## 手动配置三步

```sh
# ① IP + 掩码
ifconfig eth0 10.0.2.15 netmask 255.255.255.0 up

# ② 默认路由
route add default gw 10.0.2.2

# ③ DNS
echo "nameserver 10.0.2.3" > /etc/resolv.conf
```

## 三个错误对照

| 现象 | 根因 | 修复 |
|---|---|---|
| `ping: bad address` | 没配 DNS | 写 `/etc/resolv.conf` |
| `ping: sendto: Network is unreachable` | 没配默认路由 | `route add default gw 10.0.2.2` |
| 一直超时无响应 | 路由+DNS 都通但真到不了 | 检查 QEMU 后端/宿主机网络 |

## 诊断命令

```sh
ifconfig -a        # 看所有网卡（含未启用的）
route              # 看路由表（找 default 那条）
cat /etc/resolv.conf   # 看 DNS
ping 127.0.0.1     # 测回环
ping 10.0.2.2      # 测网关
ping 8.8.8.8       # 测外网（纯 IP，不依赖 DNS）
ping www.baidu.com # 测完整链路（含 DNS）
```

## 完整链路（ping 域名）

```
ping www.baidu.com
  ├─① DNS：查 resolv.conf → 问 10.0.2.3 → 得到 IP
  ├─② 路由：最长前缀匹配 → default → 网关 10.0.2.2
  ├─③ NAT：slirp 源地址换成宿主机 IP
  └─④ 回包：baidu → 宿主机 → slirp 查映射 → NAT 回 guest
```

## DHCP 自动配置（开机自动化）

DHCP 需要三件套配合：

| 角色 | 是谁 | 作用 |
|---|---|---|
| DHCP 客户端 | `udhcpc` | 发 discover/request，拿租约 |
| DHCP 服务端 | QEMU slirp（10.0.2.2） | 分配 IP/网关/DNS |
| 租约应用脚本 | `/usr/share/udhcpc/default.script` | 把租约写到网卡 |

### 两个必踩的坑

1. **`udhcpc` 不会自动拉起网卡**：必须先 `ifconfig eth0 up`，否则报 `Network is down`
2. **`udhcpc` 不会自己应用租约**：它把租约通过环境变量传给 `default.script` 执行，没有脚本就没有 IP

### init 脚本完整示例

```sh
ifconfig lo up
ifconfig eth0 up          # ① 先拉网卡
udhcpc -i eth0 &          # ② DHCP 协商 + 调 default.script
```

### default.script 简化版

```sh
#!/bin/sh
[ -n "$1" ] || exit 1
case "$1" in
	deconfig)
		ifconfig "$interface" 0.0.0.0 ;;
	bound|renew)
		ifconfig "$interface" "$ip" netmask "$subnet"
		[ -n "$router" ] && route add default gw "$router" dev "$interface"
		> /etc/resolv.conf
		for i in $dns; do echo "nameserver $i" >> /etc/resolv.conf; done ;;
esac
```

udhcpc 通过环境变量传入：`$interface`、`$ip`、`$subnet`、`$router`、`$dns`。

## 关键概念回顾

- **默认路由**：`0.0.0.0/0`，匹配一切未命中具体网段的目标，是"兜底路由"
- **最长前缀匹配**：内核选路由时，掩码越长（越具体）优先级越高
- **QEMU user 网络**：slirp 用户态 NAT，默认 10.0.2.0/24（网关 .2，DNS .3，guest .15）
- **NAT 副作用**：外网默认无法主动访问 guest（除非端口转发 hostfwd）
